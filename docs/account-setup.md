# 계정 개설 절차 — 5개 채널

작성 2026-09-03. 대상: 네이버 블로그, YouTube, Instagram, Threads, TikTok.

`발행 체크리스트`(`docs/publish-checklist.md`)는 **계정이 있다는 전제**로 쓰여 있다. 이 문서는 그 앞 단계다 — 계정을 만드는 것까지가 여기, 올리는 것부터가 저기다.

**이 문서에도 결정할 것이 없다.** 이름·아이디·소개문·프로필 사진·링크가 전부 정해져 있다. 사장님은 화면에 있는 칸을 **채우기만** 하시면 된다.

전부 만드는 데 **약 75분**이다. 한 번에 다 하실 필요는 없다 — 4절에 순서와 마감이 있다.

---

## 0. 다섯 채널이 공유하는 값 (먼저 준비)

계정마다 다르게 적으면 **다섯 개가 서로 다른 회사로 보인다.** 아래 값을 다섯 번 똑같이 넣는다.

| 칸 | 넣을 값 |
|---|---|
| 표시 이름 | `IB 리서치팀` |
| 아이디(핸들) | `ibresearch_kr` — 이미 있으면 `ib_research_kr`, 그것도 있으면 `ibresearch.kr` |
| 프로필 사진 | 첨부 `profile-1080.png` |
| 소개문(짧은 판) | 아래 코드블록 |
| 소개문(긴 판) | 아래 코드블록 |

**소개문 — 짧은 판** (TikTok·Threads용. 80자 제한이 있는 곳)

```
해외선물·CFD, 시작 전에 확인할 것을 정리합니다. 원금 손실 위험 있음 · 소개 수수료를 받습니다.
```

**소개문 — 긴 판** (네이버·YouTube·Instagram용)

```
해외선물·CFD를 시작하기 전에 확인해야 할 것을 순서대로 정리합니다.
증거금, 수수료, 브로커 점검, MT5 세팅.
원금 손실 위험이 있습니다. 수익을 보장하지 않습니다.
투자 판단과 책임은 본인에게 있습니다. 당사는 소개 수수료를 받습니다.
```

> **소개 수수료 문구를 빼지 마시라.** 우리는 IB(소개 브로커)라 수수료를 받는 쪽이고, 그 사실을 감추면 표시광고법 §3(기만) 문제가 된다. 그리고 실제로도 이 한 줄이 있는 계정이 없는 계정보다 신뢰를 얻는다 — `/broker` 페이지를 그렇게 쓴 것과 같은 이유다.

**아이디를 다섯 곳에 똑같이 쓰는 이유.** 한 채널에서 본 사람이 다른 채널을 찾을 때 검색하는 것이 아이디다. 채널마다 다르면 그 사람은 우리를 못 찾는다. **네이버 블로그 주소는 사실상 한 번만 정할 수 있으므로**(1절), 다섯 곳 중 하나라도 이미 선점된 이름이면 **네이버를 만들기 전에** 셋 중 다음 것으로 넘어간다.

**프로필 사진.** 다섯 채널이 전부 원으로 자른다. 그래서 글씨를 원 안쪽에만 넣어 두었다 — 정사각으로 표시하는 곳에서도, 원으로 자르는 곳에서도 잘리지 않는다. 확인용으로 원형 크롭본(`profile-1080-circle-preview.png`)도 같이 드린다. 블로그 대표 이미지·숏폼과 **같은 팔레트·같은 폰트**다.

**필요한 것.** 이메일 1개, 휴대폰 1대(문자 수신). 네이버는 네이버 계정, YouTube는 구글 계정이 따로 필요하다.

## 1. 네이버 블로그 (15분) — 가장 먼저

다섯 편 중 네 편이 여기로 가고, 첫 발행이 **9/4(금)** 이라 시간이 제일 급하다.

1. `naver.com` → 회원가입 (이미 네이버 계정이 있으면 그걸 쓰신다 — **블로그는 계정당 하나**다)
2. `blog.naver.com` 접속 → 블로그가 자동으로 개설되어 있다
3. **관리 → 기본 설정 → 블로그 정보**
   - 블로그명: `IB 리서치팀`
   - 별명: `IB 리서치팀`
   - 소개글: 위 **긴 판**
   - 블로그 프로필 이미지: `profile-1080.png`
4. **관리 → 기본 설정 → 공개 설정 → 검색 엔진 최적화(SEO)**
   - **검색 허용: 켜기** ← 이게 꺼져 있으면 지금까지 한 작업이 전부 무효다
5. **관리 → 메뉴·글 관리 → 블로그** → 카테고리 추가 → 이름 `해외선물 가이드`

> **주소(아이디)는 사실상 한 번만 정할 수 있다.**
> 블로그 주소는 네이버 아이디를 따라간다. 회원가입으로 **자동 개설된 블로그만 1회** 변경할 수 있고, 그 1회를 쓰고 나면 다시는 못 바꾼다. 주소를 바꾸면 그때까지 쌓은 검색 노출과 걸어 둔 링크가 전부 끊긴다. **0절의 아이디를 확정한 다음에 이 절차를 시작하시라.**
> 블로그명과 별명은 나중에 바꿔도 된다. 주소만 되돌릴 수 없다.

**만든 직후 확인**

- [ ] 로그아웃한 브라우저(시크릿 창)로 내 블로그 주소를 연다 → 열리는가
- [ ] 관리 화면에서 **검색 허용**이 켜져 있는가
- [ ] 카테고리 `해외선물 가이드` 가 보이는가

> **개설하자마자 5편을 몰아 올리지 마시라.** 새 블로그의 대량 발행은 검색에서 가장 불리하게 읽히는 신호다. 체크리스트의 하루 한 편 일정이 그래서 있다.

## 2. YouTube (20분) — 전화 인증을 반드시 함께

숏폼 6편 중 2편이 여기로 가고, **설명란과 고정 댓글 링크가 클릭되는 유일한 채널**이다.

1. 구글 계정으로 `youtube.com` 로그인
2. 우측 상단 프로필 → **설정 → 채널 추가/관리 → 새 채널 만들기**
   - **개인 구글 계정 이름으로 만들지 않는다.** 새 채널로 만들면 채널 이름이 개인 이름과 분리된다.
   - 채널 이름: `IB 리서치팀`
3. **채널 맞춤설정 → 기본 정보**
   - 핸들: `@ibresearch_kr`
   - 설명: 위 **긴 판**
   - 프로필 사진: `profile-1080.png`
4. **`youtube.com/verify` 로 이동 → 휴대폰 인증** ← **이 단계를 건너뛰면 계획이 깨진다**

> **전화 인증을 안 하면 설명란 링크가 클릭되지 않는다.**
> 주소는 화면에 보인다. 그런데 **글자로만 보이고 눌리지 않는다.** 영상은 잘 나가는데 아무도 랜딩에 도착하지 않고, 우리 쪽에는 "유입 0" 으로만 보여서 원인을 콘텐츠 탓으로 오해하게 된다. 이 저장소가 지금까지 겪은 사고와 성질이 같다 — **화면이 안 깨지므로 발행 뒤에야 드러난다.**
> 인증은 SMS 또는 음성 통화로 코드를 받아 넣는 것이고 2분이면 끝난다.

**만든 직후 확인**

- [ ] `youtube.com/verify` 가 **이미 인증됨**으로 나오는가
- [ ] 채널 주소 `youtube.com/@ibresearch_kr` 가 시크릿 창에서 열리는가
- [ ] (업로드 후) 설명란의 주소가 **파란 글씨로 눌리는가**

## 3. Instagram (10분) — Threads보다 먼저

**Threads는 인스타그램 계정 없이 만들 수 없다.** 별도 가입 경로는 EU 일부 지역에만 열려 있고 한국은 아니다. 그래서 이 순서를 바꾸면 4절에서 막힌다.

1. 앱 설치 → 이메일로 가입
   - 사용자 이름: `ibresearch_kr`
   - 이름: `IB 리서치팀`
2. **프로필 편집**
   - 프로필 사진: `profile-1080.png`
   - 소개: 위 **긴 판** (150자 제한이 있으니 넘치면 마지막 줄부터 지운다)
   - 링크:
     ```
     https://ib-mt5-landing.vercel.app/?utm_source=instagram&utm_medium=bio&utm_campaign=always_on&utm_content=bio
     ```
3. **설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환** → 카테고리 `교육`

> **Reels 캡션에 넣은 주소는 클릭되지 않는다.** 인스타그램에서 클릭되는 링크는 **프로필의 이 링크 하나뿐**이다. 그래서 캡션에는 "프로필 링크에 정리해 두었습니다" 라고만 적혀 있다. 이 링크를 안 넣으면 Reels 2편이 도착지 없이 나간다.

**만든 직후 확인**

- [ ] 시크릿 창에서 `instagram.com/ibresearch_kr` 이 열리는가
- [ ] 프로필의 링크를 실제로 눌러 본다 → 랜딩이 열리고 주소창에 `utm_source=instagram` 이 보이는가

## 4. Threads (5분) — 인스타그램에서 바로

1. Threads 앱 설치 → **Instagram 계정으로 로그인**
2. 프로필·사진·소개가 인스타그램에서 그대로 넘어온다. 소개만 **짧은 판**으로 바꾼다
3. 공개 프로필로 둔다

**Threads는 본문 안의 링크가 클릭된다.** 다섯 채널 중 캡션 링크가 눌리는 곳은 YouTube와 여기뿐이라, 체크리스트의 Threads 본문에는 주소가 그대로 들어가 있다.

**만든 직후 확인**

- [ ] 시크릿 창에서 `threads.com/@ibresearch_kr` 이 열리는가

## 5. TikTok (15분) — 비즈니스 계정으로 전환해야 링크가 생긴다

1. 앱 설치 → 이메일로 가입
   - 사용자 이름: `ibresearch_kr`
   - 이름: `IB 리서치팀`
2. **설정 및 개인정보 → 계정 → 비즈니스 계정으로 전환** → 카테고리 `교육`
3. **프로필 편집**
   - 프로필 사진: `profile-1080.png`
   - 소개: **짧은 판**
   - 웹사이트:
     ```
     https://ib-mt5-landing.vercel.app/?utm_source=tiktok&utm_medium=bio&utm_campaign=always_on&utm_content=bio
     ```

> **비즈니스 계정으로 전환하지 않으면 웹사이트 칸 자체가 없다.**
> 개인 계정은 **팔로워 1,000명**이 넘어야 bio 링크를 넣을 수 있다. 우리는 0명에서 시작하므로 개인 계정으로는 링크를 걸 방법이 없다. 비즈니스 계정으로 전환하면 팔로워 수와 무관하게 바로 생긴다.
> **그리고 이 칸은 모바일 앱에만 있다.** PC 웹으로 프로필을 편집하면 웹사이트 칸이 보이지 않아서 "전환했는데도 없다"로 읽힌다. 휴대폰에서 하시라.
> 링크는 반드시 `https://` 로 시작해야 등록된다.

**만든 직후 확인**

- [ ] 프로필에 웹사이트 링크가 보이는가
- [ ] 그 링크를 눌러 본다 → 랜딩이 열리고 주소창에 `utm_source=tiktok` 이 보이는가

## 6. 순서와 마감

| # | 채널 | 소요 | 언제까지 | 왜 그때까지인가 |
|---|---|---|---|---|
| 1 | **네이버 블로그** | 15분 | **9/4(금) 오전 10시 전** | 첫 발행(B5)이 이날이다 |
| 2 | **YouTube** (+전화 인증) | 20분 | 9/7(월) 저녁 8시 전 | 숏폼 1편이 이날이다 |
| 3 | **Instagram** | 10분 | 9/7(월) 저녁 8시 전 | 같은 날 Reels가 나간다 |
| 4 | **Threads** | 5분 | 9/7(월) 저녁 8시 전 | 3번이 있어야 만들 수 있다 |
| 5 | **TikTok** | 15분 | 9/7(월) 저녁 8시 전 | 같은 날 TikTok이 나간다 |

**늦어도 되는 순서.** 급한 것은 네이버 하나뿐이다. 9/4에 블로그 한 편만 나가면 일정은 유지된다. 나머지 넷은 9/7 전에만 되면 된다.

**하나도 못 만드시면.** 일정을 통째로 뒤로 미는 것이 맞다. 계정을 만든 당일에 몰아 올리는 것은 하지 않는다 — 그건 체크리스트가 막으려던 바로 그 상태다.

## 7. 다섯 개 다 만든 뒤 (한 번만, 5분)

계정이 있는 것과 링크가 도착하는 것은 다르다. **링크를 실제로 눌러 보는 것**이 이 표다.

| 확인 | 통과 기준 |
|---|---|
| 네이버 검색 허용 | 관리 화면에서 **켜짐** |
| YouTube 전화 인증 | `youtube.com/verify` 가 **이미 인증됨** |
| Instagram bio 링크 | 눌러서 랜딩 도착 + `utm_source=instagram` |
| TikTok bio 링크 | 눌러서 랜딩 도착 + `utm_source=tiktok` |
| Threads 프로필 | 시크릿 창에서 열림 |
| 신청 접수 | `curl -s https://ib-mt5-landing.vercel.app/api/health` → `"accepting":true` |

마지막 줄이 `false` 면 **링크를 뿌리지 마시라.** 유입은 생기는데 리드가 한 건도 안 남고, 나중에 복구가 안 된다.

여기까지 통과하면 `docs/publish-checklist.md` 로 넘어가신다.
