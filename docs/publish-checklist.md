## 2. 블로그 5편

### 2-0. 다섯 편 공통 — 붙여넣는 법

1. 이 이슈 첨부에서 해당 **`.html` 파일**을 내려받는다
2. 파일을 더블클릭해 **브라우저로 연다** (편집기로 열면 안 된다 — 태그가 글자로 보인다)
3. 화면에서 **Ctrl+A → Ctrl+C**
4. 네이버 블로그 글쓰기 → **본문 칸**을 클릭하고 **Ctrl+V**
5. **제목 칸**에 아래 카드의 제목을 따로 붙여넣는다
6. **본문 맨 위**에 아래 카드의 대표 이미지(`.png`)를 넣는다
7. **태그 칸**에 아래 카드의 태그 줄을 붙여넣는다 (쉼표로 구분되어 있다)

> **본문 파일에는 제목이 들어 있지 않다. 일부러 뺐다.**
> 제목이 본문에도 있으면 독자 화면에 같은 제목이 두 번 보인다. 붙여넣고 나서 지우는 방식은 언젠가 한 번 잊게 되고, 그때 화면에는 아무 오류도 안 뜬다. 그래서 파일을 만드는 자리에서 뺐고, 남아 있으면 `npm test` 가 실패하도록 검사를 걸어 뒀다.

**발행 설정 (다섯 편 동일)**

- 공개 설정: **전체 공개**
- **검색 허용: 켜기** ← 이게 꺼져 있으면 지금까지 한 작업이 전부 무효다
- 댓글 허용: 켜기 / 공감 허용: 켜기
- CCL: 사용 안 함 (또는 기본값)
- 카테고리: **해외선물 가이드** (없으면 이 이름으로 하나 만든다)

**발행 직후 확인 (2분, 매번 한다)**

- [ ] 글 맨 아래 **CTA 버튼을 실제로 눌러 본다** → 랜딩이 열리고 주소창에 `utm_content=b0X` 가 보이는가
- [ ] 표가 표로 보이는가 (`|---|` 같은 기호가 글자로 남지 않았는가)
- [ ] 대표 이미지가 목록에서 썸네일로 잡히는가
- [ ] 아래 **발행 기록표**에 글 주소를 적는다

## 3. 숏폼 6편

### 3-0. 여섯 편 공통 — 올리기 전에 하는 것

**① 음악을 얹는다** (편당 5분, 사장님 결정 2026-09-03)

렌더본은 **무음**이다. 컷 길이가 전부 0.5초의 배수라 **120 BPM 곡의 첫 박을 영상 0초에 맞추면 모든 하드컷이 박자 위에 떨어진다.** 60·90·150 BPM 은 어긋난다.

- **가장 쉬운 방법**은 각 앱의 오디오 라이브러리에서 고르는 것이다(Reels·TikTok). 플랫폼 음원을 쓰면 저작권 문제가 없고, 그 음원을 타는 노출도 같이 붙는다.
- 가사가 있는 곡은 자막과 겹쳐 읽는 속도를 떨어뜨린다. **무가사(instrumental)** 로 고른다.
- YouTube Shorts 는 앱에서 음원을 얹거나, 무음 그대로 올려도 된다. 자막만으로 내용이 전달되게 만들어 둔 렌더본이다.

**② 커버(썸네일)를 고른다** — 세 채널 모두 **0.5초 지점 프레임**을 고른다. 첫 컷의 훅 문구가 그대로 커버가 된다. 커버에 글씨를 따로 얹지 않는다(이미 큰 글씨가 있다).

**③ 링크를 놓는 자리** — 채널마다 다르다. 이걸 틀리면 링크가 클릭되지 않는다.

| 채널 | 링크가 클릭되는 자리 | 캡션 링크 |
|---|---|---|
| YouTube Shorts | 설명란 · 고정 댓글 | 클릭됨 |
| Instagram Reels | **프로필 bio 링크만** | 클릭 안 됨 |
| TikTok | **프로필 bio 링크만** (팔로워 1,000 미만 기준) | 클릭 안 됨 |
| Threads | 본문 | 클릭됨 |

그래서 Reels·TikTok 캡션에는 `프로필 링크` 라고 적고, **프로필 bio 에는 아래 주소를 한 번만 넣어 두면 된다** (상시 링크, 매번 바꾸지 않는다).

```
Instagram bio : https://ib-mt5-landing.vercel.app/?utm_source=instagram&utm_medium=bio&utm_campaign=always_on&utm_content=bio
TikTok  bio   : https://ib-mt5-landing.vercel.app/?utm_source=tiktok&utm_medium=bio&utm_campaign=always_on&utm_content=bio
```

> bio 링크는 하나뿐이라 **어느 영상이 데려온 유입인지 링크로는 갈리지 않는다.** 대신 아래 발행 기록표에 올린 날짜를 적어 두면 유입이 뛴 날로 대조할 수 있다. 이걸 링크로 나누려면 편당 짧은 주소를 따로 만들어 bio 를 매번 바꿔야 하는데, 손이 많이 가고 잊기 쉬워서 지금 단계에는 권하지 않는다.

**④ 공개 설정** — 세 채널 모두 **전체 공개**. YouTube 는 `아동용 아님`, 카테고리 `교육`.

## 5. 첫 주가 끝나면 보는 것

발행이 다 끝난 뒤(9/12 이후) 아래 세 가지만 본다. 그 전에는 숫자가 너무 적어 판단이 안 된다.

1. **네이버 유입** — 블로그 통계에서 유입 검색어. 우리가 노린 키워드로 들어오는가.
2. **랜딩 도달** — 신청 폼에 리드가 남았다면 `utm_content` 가 어느 값인가. 어떤 글·영상이 데려왔는지 여기서 갈린다.
3. **텔레그램 문의** — 봇으로 들어온 질문. 이게 다음 콘텐츠 주제다. **사람이 실제로 묻는 것보다 좋은 주제 목록은 없다.**

리드가 0건이어도 그 자체가 정보다. 유입은 있는데 리드가 0이면 랜딩 문제이고, 유입이 없으면 콘텐츠·노출 문제다. 둘은 고치는 방법이 완전히 다르다.
