# W01-E02 punchy 편집용 컷 시트

톤: 강한 훅 · 빠른 컷 · 큰 글씨. 음악은 사장님이 편집에서 얹습니다. 모든 내용은 **정식 해외 브로커 정규 계좌 기준**이며, 확인되지 않은 브로커별 금액은 쓰지 않았습니다.

## 훅 A/B

- A안(선택): `수수료 한 줄만 봤다? / 총비용은 다를 수 있습니다.` — 첫 2초 안에 누락 비용의 손해 회피 동기가 선명합니다.
- B안: `왕복 수수료 말고 / 뭘 더 봐야 할까요?` — 정확하지만 질문의 답을 이해하려면 배경지식이 필요해 A안보다 약합니다.

## 내레이션 가이드

무음 카드형 렌더본이므로 녹음은 선택입니다. 녹음한다면 아래처럼 짧게 끊습니다.

`수수료 한 줄만 봤다면, / 총비용은 다를 수 있습니다. / 먼저 편도인지 왕복인지 보세요. / 하루를 넘기면 붙는 보유 비용과 / 환전 비용도 / 따로인지 확인하고요. / 스프레드와 슬리피지도 / 체결 과정의 비용입니다. / 같은 상품, 같은 거래 수량, / 같은 왕복 기준으로 보세요.`

## 6단계 자체 검수

1. **훅 — 통과.** A안을 선택했습니다. 누락 비용의 손해 회피 동기가 첫 2초에 걸리고, B안보다 배경지식 요구가 적습니다.
2. **시놉시스 — 통과.** 기준 확인 → 별도 항목 → 체결 과정 → 같은 조건 비교 → CTA로 끊김 없이 이어집니다. 최장 컷 2.5초이며 늘어지는 구간이 없습니다.
3. **멘트 — 통과.** 한 문장을 짧게 끊었고 문어체·번역투를 제거했습니다. 화면 자막은 멘트보다 짧게 축약했습니다.
4. **컴플라이언스 — 통과.** 수익·원금 보장, 우열·비방, 할인·리베이트·캐시백·페이백·환급, `최저` 표현이 없습니다. 정식 해외 브로커 정규 계좌 기준과 마지막 2초 고지 4줄을 넣었습니다.
5. **CTA — 통과.** 세 영상과 Threads 모두 `내 조건으로 비용 계산받기`로 통일했고 채널별 `utm_content=sf_002` 링크를 넣었습니다.
6. **팩트 — 통과.** 브로커별 금액을 쓰지 않았습니다. 별도 비용은 단정하지 않고 `포함 여부는 계좌 조건마다 확인`으로 한정했습니다.
