# shorts-render — 자막 카드형 숏폼 렌더러

기획서가 아니라 **재생되는 mp4** 를 뽑기 위한 도구다. 촬영 없이 만들 수 있는 구간(자막 카드,
훅, 핵심 정리, CTA, 고지)만 담당한다. 실사 촬영분·나레이션·음악·업로드는 사장님 몫이다.

## 실행

```bash
cd shorts
npm i ffmpeg-static                       # node_modules 는 커밋하지 않는다
FFMPEG=$PWD/node_modules/ffmpeg-static/ffmpeg \
  python3 render.py scenes/w1-e1-youtube.json out/w1-e1-youtube.mp4
```

렌더는 **결정적이다.** 같은 장면 JSON 으로 다시 돌리면 mp4 가 바이트 단위로 같다
(`w1-e2-tiktok-punchy` sha256 `79d519fe...` 로 확인, 2026-09-03). 그래서 `out/` 은
커밋하지 않는다 — 영상이 필요하면 여기서 다시 만들면 된다.

- 출력: 1080x1920 / 30fps / H.264 / 무음 AAC 트랙 포함 (플랫폼 업로드 호환용)
- 시스템 ffmpeg 는 이 환경에 없다. `npm i ffmpeg-static` 으로 받으며 sudo 가 필요 없다.
- 한글 폰트는 Noto Sans CJK KR (`NotoSansCJK-*.ttc`, index 1) 를 쓴다.

## 장면 JSON

```jsonc
{
  "scenes": [
    {
      "dur": 2.0,                    // 컷 길이(초)
      "kind": "hook",                // hook | point | cta | disclaimer
      "kicker": "해외선물 입문",       // 상단 작은 라벨 (생략 가능)
      "headline": ["증거금 채워도", "청산?"],  // 줄 단위 배열
      "headline_size": 118,          // 기본 92
      "emphasis": 1,                 // 빨강 강조할 headline 줄 index
      "sub": ["보조 설명 한 줄"],     // 생략 가능
      "footer": "내 조건으로 비용 계산받기",  // 하단 버튼형 (생략 가능)
      "note": "하단 작은 각주"        // 생략 가능
    }
  ]
}
```

- `kind: "disclaimer"` 는 배경이 검정으로 바뀌고 진행바가 사라진다. 마지막 2초 고정 고지에 쓴다.
- 컷 전환은 0.16초 페이드, 헤드라인은 줄마다 0.1초씩 밀려 등장한다.
- 진행바는 전체 길이 대비 현재 위치를 상단에 표시한다.

## 스타일 — `punchy` 가 기본값이다

사장님이 2026-09-03 에 톤을 정하셨다: **강한 훅 · 빠른 컷 · 큰 글씨**, 음악은 편집에서 사장님이
얹는다. 새 편은 별도 지시가 없으면 `punchy` 로 만든다. 기존 `calm` 스타일은 비교용으로만 남긴다.

```jsonc
{
  "style": "punchy",
  "bpm": 120,                      // 컷 길이 검증 기준
  "scenes": [
    {"dur": 1.5, "kind": "hook", "tone": "red",
     "headline": ["왜 잘려?"], "headline_size": 180, "emphasis": 0}
  ]
}
```

`calm` 과 다른 점:

- **`tone`** 으로 컷마다 배경색을 바꾼다: `dark`(남색) / `red`(경고) / `blue`(전환·정리) / `black`(고지).
  컷이 짧아 배경색 전환 자체가 리듬이 된다.
- **페이드가 없다.** 하드컷이고 헤드라인은 0.14초 안에 한꺼번에 올라온다. 줄마다 지연을 주면
  컷이 느리게 읽혀서 punchy 가 아니게 된다.
- **`emphasis`** 는 형광 노랑 하이라이트가 가로로 밀려 들어오고 덮인 글자가 검정으로 뒤집힌다.
  **컷당 한 줄만** 건다. 두 줄에 걸면 시선이 갈라져 효과가 죽는다. 정수 또는 정수 배열.
- 기본 글자 크기가 130 이다(`calm` 은 92). 훅은 180~260 까지 쓴다.

### 컷 길이는 0.5초 배수여야 한다

`style: "punchy"` 는 렌더 전에 모든 `dur` 이 `60/bpm` 의 배수인지 검사하고, 아니면 렌더를 거부한다.
120 BPM 기준 0.5초다. 음악을 나중에 얹는데 컷이 비트 격자에서 벗어나면 어떤 곡을 깔아도 컷과
박자가 어긋나고, **어긋난 것은 렌더된 영상만 봐서는 안 보인다.** 그래서 파일 단계에서 막는다.

편집자에게 넘길 타임코드 표는 `w1-e1-punchy-cutsheet.md` 형식으로 같이 낸다.

### 컷 길이 기준

- 훅 1.0~1.5초, 일반 컷 1.5~2.0초, 마무리 2.5초, CTA 2.0~3.0초, 고지 2.0초 고정
- **최장 컷 3.0초를 넘기지 않는다**
- 총 길이 23~30초, 컷 13개 이상, 평균 2.0초 이하


## 발행 전 고정 규칙

- CTA 문구: `내 조건으로 비용 계산받기`
- 리베이트·캐시백·페이백·환급, 수익·원금 보장, 확정 수익률, 타 브로커 비방 표현 금지
- 확인되지 않은 수치는 넣지 않는다
- 외부 계정 업로드와 최종 발행 승인은 사장님이 한다
