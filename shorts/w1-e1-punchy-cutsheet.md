# W01-E01 punchy 편집용 컷 시트

톤: 강한 훅 · 빠른 컷 · 큰 글씨 (사장님 지시 2026-09-03). 음악은 사장님이 편집에서 얹습니다.

## 음악 얹는 법

**모든 컷 길이가 0.5초의 배수입니다.** 120 BPM 기준 1박이 0.5초라서,
**120 BPM 곡의 첫 박을 영상 0초에 맞추면 모든 컷이 박자 위에 떨어집니다.**
60 / 90 / 150 BPM 은 어긋납니다. 곡 BPM 이 다르면 편집기에서 120 으로 맞추거나,
아래 타임코드에 맞춰 곡 쪽을 잘라 주세요.

컷 전환이 하드컷(페이드 없음)이라 박자와 어긋나면 바로 티가 납니다. 이게 이 시트가 필요한 이유입니다.

## 고치는 법

```bash
cd shorts-render
FFMPEG=$PWD/node_modules/ffmpeg-static/ffmpeg \
  python3 render.py scenes/w1-e1-youtube-punchy.json out/w1-e1-youtube-punchy.mp4
```

컷 길이를 0.5초 배수가 아닌 값으로 바꾸면 렌더러가 거부합니다. 박자가 어긋난 영상이 나가는 것을 막기 위한 것입니다.
